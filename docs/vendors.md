# Реестр вендоров

Блок «С какими продуктами работаем» строится из одного файла, `content/vendors.json`.
Из него при сборке генерируются:

- сетка карточек на `/licensing` (`#partners`, между маркерами `<!-- VENDORS:CARDS -->`);
- лента логотипов на главной (`#partners-teaser`, между маркерами `<!-- VENDORS:CAROUSEL -->`, обе копии: видимая и `aria-hidden`).

Руками содержимое между маркерами не правим: `npm run build` (или `npm run generate:vendors`) перезапишет его.
Генератор: `scripts/lib/vendors.cjs`, проверка: `scripts/check-vendors.cjs` (входит в `npm run build` и `npm test`).

## Как добавить вендора

1. Положите официальный логотип в `assets/partners/` (SVG или PNG). Берите только из пресс-кита, бренд-центра или шапки сайта вендора, форму и цвета не меняйте.
2. Добавьте объект в массив `vendors` в `content/vendors.json` по шаблону ниже. Источник логотипа обязательно запишите в `logoSource`.
3. Если нужна страница вендора, создайте её (как `veeam.html`), добавьте в `scripts/build-site.cjs`, `scripts/dev-server.cjs` и `content/navigation.json`, затем укажите `pageUrl`.
4. Запустите `npm run build`: он перегенерирует блоки и проверит реестр.
5. Откройте `/licensing` и главную: карточка на месте, логотип в ленте виден, лента не переполняется.

## Шаблон

```json
{
  "id": "vendor-id",
  "name": "Название",
  "logo": { "src": "/assets/partners/vendor-id.svg", "width": 0, "height": 0, "alt": "Название" },
  "logoSource": "Откуда взят логотип: URL или название пресс-кита",
  "category": "Категория",
  "description": "Одно-два предложения: что это за продукт.",
  "bullets": ["Что делаем мы 1", "Что делаем мы 2", "Что делаем мы 3"],
  "siteUrl": "https://www.example.com/",
  "pageUrl": "/vendor-page",
  "order": 90,
  "showInCarousel": true,
  "enabled": true
}
```

## Поля

| Поле | Обязательно | Описание |
| --- | --- | --- |
| `id` | да | kebab-case, уникальный; карточка получает `id="partner-<id>"` |
| `name` | да | Название для ссылок («Сайт <name>», «Подробнее о <name>») |
| `logo` | да | `{src, width, height, alt}`; необязательно `imgClass` (классы на `<img>`) и `caption` (текст рядом со значком, как у Adobe). Временная заглушка: `{ "type": "text", "text": "Название" }` |
| `logoClass` | нет | Модификатор обёртки логотипа, например `partner-logo--jivo` |
| `logoSource` | да | Источник логотипа |
| `category` | да | Короткая категория над описанием |
| `description` | да | 1–2 предложения |
| `bullets` | да | Ровно 3 пункта блока «Что делаем мы» |
| `siteUrl` | нет | Внешний сайт вендора (https), ссылка «Сайт …» |
| `pageUrl` | нет | Наша страница вендора, ссылка «Подробнее»; страница должна существовать |
| `order` | да | Порядок в сетке и ленте |
| `showInCarousel` | нет | По умолчанию `true` |
| `enabled` | да | `false` скрывает вендора везде |

Глобальное поле `partnerLabel` («Партнёр») выводится одинаково на каждой карточке. Индивидуальных статусов нет:
в реестр попадают только подтверждённые вендоры. Слова «официальный» и «авторизованный партнёр» не используем.
Цены и формы в карточки не добавляем.

## Лента на главной

Анимация задана в `src/input.css` (`.partner-marquee-track`, 40 секунд на цикл при 8 логотипах). Если число логотипов
заметно меняется, подберите длительность так, чтобы скорость оставалась около 40–50 px/s: это проверяет `npm run check:motion`
(нужен запущенный `npm run dev`).
