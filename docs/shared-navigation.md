# Общий справочник навигации NEXCEL

## Что было до изменения

Основной репозиторий: `Tarlan2006/Nexcel_website`, основная ветка `main`. Корневые HTML-страницы используют общие `partials/header.html` и `partials/footer.html`. В production `scripts/build-site.cjs --inline-partials` встраивает их в страницы после генерации новостей. В локальном dev `assets/include-partials.js` загружает их по HTTP и инициализирует существующее поведение меню. Отдельных списков меню для каждой страницы нет.

Списки услуг повторялись в desktop, mobile и футере. Компания, контакты, соцсети и юридическая строка находились непосредственно в HTML шаблонов. Сайт только на русском. Основа задачи — актуальная удалённая main, а не более старая рабочая копия с незавершёнными правками других задач.

## Как устроено сейчас

| Назначение | Файл |
| --- | --- |
| Единственный редактируемый справочник | `content/navigation.json` |
| Публичный результат | `shared/nav.json`, в сборке `dist/shared/nav.json` |
| Генератор | `scripts/generate-navigation.cjs`, `scripts/lib/navigation.cjs` |
| Макеты без изменения дизайна | `src/shared/header.template.html`, `src/shared/footer.template.html` |
| Существующие иконки соцсетей | `src/shared/icons/*.svg` |
| Схема v1 | `schemas/nav.schema.json` |
| CLI валидации | `scripts/validate-nav.cjs` |
| Проверки и уведомление photo | `.github/workflows/notify-subsites.yml`, `scripts/notify-subsites.cjs` |
| Заголовки | `_headers` → `dist/_headers` |

`services` одновременно формирует верхнее меню обоих размеров и колонку услуг в футере; новая услуга добавляется одной записью. Различающиеся исторические подписи сохранены, например «Автоматизация Excel и Google Sheets» / «Автоматизация Excel». Внешние ссылки в JSON абсолютные HTTPS; при генерации HTML ссылки самого nexcel.kz сохраняют прежний относительный вид для корректной работы активных разделов и локального preview. `mailto:` собирается только в HTML из поля email, в JSON href с таким протоколом нет.

Все тексты получены из актуальных шаблонов. Для новой ссылки «Фото на документы» использованы название и адрес из задачи. Логотип в JSON указывает на существующий `https://nexcel.kz/assets/logo.svg`; видимый логотип сайта и стили не заменялись. `kk` в локализованных полях пуст, поскольку переводов основного сайта нет. Публичная юридическая строка соответствует текущему футеру: компания и БИН; удалённые ранее адрес и ФИО не восстановлены.

Сгенерированные JSON и partials коммитятся, но не редактируются вручную. Build генерирует их до Tailwind и копирования статических файлов. CI сначала проверяет актуальность копий, затем схему, юнит-тесты и build. `src`, `content`, `schemas`, scripts и workflow не попадают в публичную сборку.

## Заголовки и уведомление

Для `/shared/nav.json`: CORS `https://photo.nexcel.kz`, кэш 300 секунд, JSON UTF-8. Паттерн поддомена в `Access-Control-Allow-Origin` не используется — он невалиден для браузеров. Текущие CSP и остальные заголовки сайта сохранены; на HTML CORS не добавлялся.

Workflow фильтрует push в main/master по JSON, данным, макетам, генератору и связанным файлам. В pull request выполняется только проверка, без уведомления. При отсутствии `PHOTO_DEPLOY_HOOK` уведомление пропускается. При наличии секрета проверяется фактическая публикация нового JSON; GET использует параметр revision и обход локального кэша. Только после совпадения содержимого отправляется один POST на hook. Это предотвращает пересборку photo со старым JSON во время публикации основного сайта. Сбой POST не повторяется автоматически, чтобы не запускать несколько деплоев; URL секрета в ошибки не включается.

Порядок ручной настройки секрета и hook описан в README. Реальный POST без предоставленного hook не имитируется. Завершение сборки поддомена — отдельный результат Cloudflare.

## Проверки

- `npm test`: 10/10 — структура JSON, HTTPS и RU/KK поля, дата, повторы, актуальность генерации, новая услуга из одной записи, экранирование HTML, отсутствие секрета, ожидание публикации и один POST, скрытие URL в ошибках.
- `npm run build`: успешно, 25 HTML-страниц с общими partials и 12 новостных публикаций; публичный JSON включён в dist.
- `npm run check:navigation`: успешно, 26 переходов, desktop dropdown, mobile accordion, клавиатура, активные ссылки, отказ загрузки partials.
- `npm run check:cloudflare`: 90 HTTP-проверок в локальной среде Cloudflare, включая JSON/CORS/cache/MIME, старые страницы и недоступность исходников по HTTP.
- `npm run check:seo`: успешно, 25 страниц.
- `npm run check:security`: успешно, 48 проверок страниц/размеров экрана, 66 действий с кнопками, клавиатурная навигация, CSP и исключение секретов.
- Сравнение DOM исходных и сгенерированных шапки/футера: существующие теги, атрибуты, SVG и тексты совпадают после исключения новых ссылок photo. CSS и lock-файл зависимостей не изменились.

Проверки реальных телефонов здесь не заявляются. Снимки локального preview и подробные логи находятся в игнорируемой `.review/`.

Проверка публичного URL и результат CI будут добавлены после push.
